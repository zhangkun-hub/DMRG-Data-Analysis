## 2. 候选相物理判据矩阵

### 2.1 SC（超导关联与超导相）

| 项 | 内容 |
|---|---|
| 物理定义与相邻概念 | 配对关联（任意强度的两点关联）→ 准长程配对（幂律衰减，指数 K_sc）→ 真长程超导序（热力学极限）。相邻：CDW 诱导的配对振荡、条纹背景配对、参考键边界效应 |
| 必需观测量（定义性） | SC 配对关联衰减指数 K_sc（多参考键一致）；SC 配对 SF 的 q=0 行为；配对对称性幅度/符号通道 |
| 辅助观测量（交叉验证） | 电荷指数 K_ρ（Luther-Emery 关系 K_sc·K_ρ=1，准 1D 圆柱适用【文献核实：arXiv:2303.16487】）；自旋关联指数衰减（自旋有隙）；单粒子关联指数衰减 |

| 长距离/有限尺寸要求 | **指数对比**（K_sc < K_cdw 等）；**D 外推**（小 D 的平坦配对关联会伪装长程序，需 M→∞ 二阶外推【文献核实：PNAS SI 6-leg t-J】）；多宽度/多长度趋势 |
| 质量门与校准 | 稳定性 verdict、osc 层偏差警告、SU(2) 误差（**未校准**——真实数据 0.1~0.2 量级【数据观察】）、参考键一致性（P2 可比性） |

| 当前数据足够？ | 关联级足够；**长程序级不足**（无同口径尺寸序列、单宽度） |

## 3. d+id 与手性证据专门章节

### 3.1 三级结论（严格区分）

1. **与 d+id 相容**：幅度/符号观测与 d+id 预期的实数部分一致——**最弱**，不构成支持。
2. **支持 d+id 的部分证据**：实数部分的多通道一致性 + 其他交叉验证（如虚部敏感量的间接效应）——**需统计支持判定**（bootstrap 未实现 → supported_candidate_status=not_evaluated）。
3. **已确认 d+id 手性态**：复数相对相位 ±π/2 的直接证据——**当前数据 not_measurable**。

### 3.2 专门证据表

| 证据项 | 当前状态 | 判定能力 |
|---|---|---|
| 键方向 A/B/C 幅值比（观测） | 可达（振幅矩阵观测 + 模板距离描述）【代码核实】 | 仅描述；幅值不等 ≠ 手性 |
| 实数相对符号（逐元素 + 逐对积） | 可达（5B-3）【代码核实】 | 观测；不构成相位证据 |
| 复数配对振幅/相对相位 | **数据无**（实值 MPS，USE_REAL=1【代码核实：B1.1】） | phase=blocked_by_data——能力受限，非反证 |
| 相对相位 ±π/2 判定 | not_measurable | — |
| 手性/TRSB 独立诊断（边界流、自发电流、μSR 类） | 无任何测量 | not_measurable |
| 有限尺寸/边界/参考键假象核查 | 部分可达（osc 层偏差警告、参考键一致性） | 质量诊断级 |

### 3.3 五项原则（P0 冻结，重申）

1. 实值配对关联/符号不足以证明相对相位 ±π/2。
2. 单参考键/单方向不能独立确定完整配对表示。
3. 幅值不等、符号变化、单通道占优 ≠ 手性。
4. 相位信息缺失 → **数据能力受限（blocked_by_data/not_measurable），不是物理反证**。
5. "相容 / 部分证据 / 已确认"三级不得混淆。

### 3.4 理论依据（【文献核实】）

- 蜂窝 t-J/RVB 框架：手性 d+id' 为近 Mott 态有利序，破缺时间反演，Chern 数 ±2——**Black-Schaffer & Doniach, PRB 75, 134512 (2007)**；t-J 重整化平均场 + QMC 确认 d+id' 宽 U 区有利、混合手性被排除——**Black-Schaffer, Wu & Le Hur, PRB 90, 054521 (2014)**
- fRG：掺杂下 d+id 与 f 波三重态配对不稳定性从密度波区涌现——**Honerkamp, PRL 100, 146404 (2008)**
- 注意：这些是**特定模型/参数区间的理论预言**，不是"d+id 必然发生"的普适事实；本项目判据不得直接移植其阈值。

### 3.5 最小新增测量方案（解除歧义）

复值 MPS 计算（或 TRSB 敏感探针）：
- 计算复值基态下的 ⟨Δ†_ref Δ_t⟩ 复数关联 → 提取相对相位 φ(r)，检验 φ→±π/2 的平台行为
- 与实数符号模式交叉验证（复数相位应约化到实值极限下的符号结构）
- 若无法新算：保持 not_measurable，不在软件侧绕过

## 7. 当前数据能够回答的问题

1. 配对/自旋/电荷关联的**数值观测与衰减分类**（8 类数值分类，非物理结论）。
2. 配对对称性的幅度各向异性、实数符号与层内逐对积**观测**。

4. SU(2) 偏差、振荡偏差、可比性等**质量诊断**。
5. d+id 相位能力的**明确受限声明**（blocked_by_data）。
6. 能量外推与 MAD 敏感性诊断。
7. 全部上述证据的统一追溯与聚合（P1-C/P1-D 设施）。

## 8. 当前数据不能回答的问题

1. 热力学极限超导长程序（无同口径尺寸序列、无 D 收敛序列、单宽度）。
2. d+id 复数相对相位/手性/TRSB（实值数据，原理不可测）。
3. PDW 判定（单参考键受限）。
4. 条纹候选判定与分类（无尺寸序列、无位置分辨关联）。
5. 体相 CDW/SDW 确认（无尺寸依赖）。
6. 任何"支持级"候选结论（统计支持判定未实现 + 判据未授权）。
