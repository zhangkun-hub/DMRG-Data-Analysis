### 2.1 测量端误差记录（未来新测量的必选设计要求，P1-G.19）

依据 P1-G.18 审计：现有优化日志的 TruncErr 只能作 MPS 质量档案
（映射粒度 doping × D 档），测量日志无误差记录——**不存在已验证的
独立噪声证据**，`tail_state` 恒 inconclusive_noise_floor。未来新测量
必须输出以下**三类量**（物理含义不同，分别存储、分别验证，不得混
为一个噪声估计）：

| 量 | 定义（待测量端确认后填写正式公式） | 存储 | 独立噪声用途 |
|---|---|---|---|
| `within_group_scatter` | 同距离组内目标键（或镜像对）之间的离散度 | 与主数据同构（每距离点一个值） | 首选：`estimate_noise_floor` 的 intra_scatter 分量的真实输入 |
| `repeat_measurement_scatter` | 同一 MPS、同一测量协议下重复测量的波动（仅当测量过程确有可重复采样机制时输出；无该机制则明确记录"不适用"而非编造） | 与主数据同构 | 组间重复性验证 |
| `truncation_error_record` | 优化过程截断误差档案（沿用优化日志 TruncErr 的完整记录） | 日志 | 仅作 MPS 质量档案，**不作为**测量误差 |

**P1-G.20 源码核实后的三类记录边界**（【源码核实】measureSC_fix_ref_extension.cpp
/ UltraDMRG finite_mps_measu_disk.h:332-361、finite_mps_measu_memory.h:41-48、
two_site_update_finite_vmps_mpi_impl_continue.h:395-402）：

| 记录 | 当前状态 | 允许用途 | 禁止的推断 |
|---|---|---|---|
| `within_group_scatter` | 样本定义与统计意义待验证（键间差 = 空间非均匀 + 对称性偏差 + 截断效应混合；组内相关） | 定义明确后进行组内差异诊断 | 直接等同于独立测量噪声或误差棒 |
| SU(2) 通道一致性残差 | 可算（symmetry_check 已有；P1-G.23：MPS 仅显式保 U(1)，残差混合截断/优化/态对称偏离） | 诊断自旋通道关系的一致性及其随 D 的变化 | 将所有残差直接归因于截断误差 |
| 空间对称轨道偏差（y+2） | 几何映射已核实（P1-G.23：y+2 是近邻图自同构，A∪B 集合封闭但 A/B 标签在周期边界处互换；态对称性未验证） | 在几何映射、reference/target 共同变换及态对称性验证后作空间对称性诊断 | 将几何对称性直接等同于态对称性 |
| `repeat_measurement_scatter` | 当前无适用采样机制（确定性缩并） | 未来存在有效采样机制后再评估 | 将确定性重复执行或不同 D 的差异伪装成重复测量噪声 |
| `truncation_error_record` | 可从优化日志整理 | 记录 MPS 优化质量历史 | 直接转换为关联函数误差棒或噪声底 |

三类量（及以上派生诊断）必须分别命名、分别保存、分别验证，不得
统一包装成一个泛化的 `std` 或 `noise`。

**两道独立验收门槛（冻结）**：

- **门槛一：统计实现验证**——统计量能否被正确计算、保存和读取：
  样本索引与样本数正确；分组/归一化/缺失值处理符合定义；合成测试
  恢复预设统计量；输出格式与数据接口兼容。
- **门槛二：物理有效性验证**——统计量是否足以支持预期物理解释：
  样本集合物理含义明确；样本相关性已分析；真实空间差异与数值误差
  的混淆风险已评估；用作噪声/信号推断的依据经独立验证。
- **通过统计实现测试 ≠ 通过物理有效性验证**。对
  `within_group_scatter`，合成测试恢复注入散布不证明真实数据中的
  散布来自噪声；对 `truncation_error_record`，实现测试只验收提取与
  存储，不授权其作为关联函数误差估计。
- 三条明确推论（P1-G.23）：① 可以正确计算某个残差，不代表该残差
  能够估计误差；② 可以证明一个几何映射，不代表近似 MPS 或实际
  物理态保持相应对称性；③ 可以观察到残差随 D 减小，不代表已证明
  残差由截断误差主导。即使通过这些局部验证，也不能自动启用新的
  尾部噪声判定。

**正式启用条件**（任何候选统计量参与尾部信噪比判定，必须**同时**
满足）：

1. 统计量定义和样本集合明确；
2. 独立性或相关性依据得到书面说明；
3. 验证方法在启用前确定，并实际通过验证；
4. 通过物理有效性审查，确认该量确实能支持预期用途。

只新增字段、只保存一个数值、只通过合成数据测试，均不足以启用新的
噪声底判定；任何统计量均不得绕过上述门槛自动令 `tail_state` 离开
`inconclusive_noise_floor`。

**空间对称轨道统计量（C3）的前置条件**（未满足前不得把轨道内偏差
当作噪声底）：

1. 核实对称操作对当前有限几何与哈密顿量成立（y+2 已核实；
   y+1/y+3 不成立）；
2. 明确 reference bond 与 target bond 如何**共同变换**；
3. 明确键方向、A/B 标签、子格与周期边界映射（A/B 标签非对称
   不变量，已在 P1-G.23 核实）；
4. 单独评估实际量子态是否可能自发破缺该空间对称性；
5. 验证样本的物理等价性与相关性。

**JSON 兼容性审慎表述**：`Physical_Data_Record.py` 的解包逻辑
（`[value, *_]`）可忽略额外元素，这只是**初步的局部兼容性依据**，
不等于整个读取链路已通过第三元素扩展的兼容性验证（其他读取路径
尚未审计）。因此：本阶段**不实施** JSON 格式扩展；未来若正式设计
第三元素方案，必须先审计所有相关读取路径并通过回归测试；独立旁
文件等替代方案保留为设计选项，不必现在定案。

**当前实现状态冻结（P1-G.24）**：本阶段只修正文档——不实现任何
scatter 字段；不扩展 JSON 格式；不改变任何现有噪声估计公式；
不改变 `tail_state`（恒 inconclusive_noise_floor）；不注册
`sc_lro_v1`；不新增测量/计算任务（第三个 D 档仅为可选证据来源的
定位，见 Evidence §3.5 P1-G.23 小节）。

## 4. 跨尺寸可比性矩阵（N200 ↔ N400）

| 维度 | 判定 |
|---|---|
| 测量源码（DMRGtJModel） | **不可比**：跨 44269cb 功能变更（N200 前 / N400 后） |
| 库（UltraDMRG） | 大概率同版本（11fa2c3），但工作区干净性**无法核实** |
| D 调度 | **不可比**（档位不同） |
| 源点 / refbond / measure 版本 | **不可比**（身份不同；P2 机制已覆盖） |
| 几何 / q 网格 | 可比（同构、同参数数值相同） |
| 结论 | **N200 与 N400 不得合并为同口径尺寸序列**；可比项（几何/q 网格）不抵消不可比项 |

## 5. 新尺寸验证方案（先验证协议可复现性，再扩展）

1. **锁定**：DMRGtJModel 打 tag（如 `measure_sc_lro_protocol_v1`），记录
   UltraDMRG HEAD 与工作区干净性检查结果；协议参数（D 调度、收敛标准、
   measure 版本、refbond/源点选择）写入数据清单随数据保存
2. **单尺寸复现**（新尺寸之前必须先做）：用锁定协议重算一个 N=200 尺寸
   （同掺杂、同 refbond），与现有 N200 数据对比——只验证**同协议可复现
   性**（不解决与旧数据的可比性）；复现通过后旧数据仍按 §6 处理
3. **新尺寸**：按锁定协议生成新尺寸数据（尺寸数**待物理确认**，不预设
   最小数）；每个尺寸 ≥2 档 D 做 D 收敛检查（§3.5 尾部信噪比需独立噪声
   来源，见 SC_LRO_Evidence_Requirements.md）
4. **验收口径**沿用 G.9 文档 §4 三分类（通过/失败/证据不足）

## 6. 阻断条件（任一满足 → 该数据禁入同口径尺寸外推）

1. 测量源码 commit 无法确认（或确认跨过测量功能变更 commit 且无法证明
   该变更不影响相关观测量）→ **阻断**；
2. D 调度不同 → **阻断**（除非补充同调度档位数据）；
3. 源点 / refbond / measure 版本身份不同 → **阻断**（P2 机制已覆盖该不可比，
   不得绕过）；
4. 库工作区干净性无法确认且无重算复现 → 该批数据标记"来源未核实"，
   不得默认同口径。

**现状判定**：按上述阻断条件，现有 N200 与 N400 **全部处于阻断状态**
（§4 矩阵），任何现有数据组合都不构成"同口径尺寸序列"——这是 SC-LRO
尺寸外推证据（E2）缺失的直接原因。
