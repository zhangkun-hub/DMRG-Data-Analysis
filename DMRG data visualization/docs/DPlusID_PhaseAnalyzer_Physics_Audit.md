## 1. 当前项目实际数据结构

### 1.1 测量算符定义 **[源码]**

- 配对测量程序：`DMRGtJModel/src/measureSC_fix_ref_extension.cpp`（honeycomb 用；
  `measureSC.cpp` 为 legacy square 版，不适用）。
- 算符：`bupc/bupa/bdnc/bdna` = c↑†/c↑/c↓†/c↓（t-J 无双重占据）。
- 四通道定义（两套程序一致）：
  - a = [bupc, bdnc, bupa, bdna] → ref 键上 c↑†c↓†、target 键上 c↑c↓
  - b = [bdnc, bupc, bupa, bdna] → ref 键上 c↓†c↑†（自旋顺序交换）
  - c = [bupc, bdnc, bdna, bupa] → target 键上 c↓c↑（自旋顺序交换）
  - d = [bdnc, bupc, bdna, bupa] → ref 与 target 都交换
- 语义：a = ⟨Δ†(ref) Δ(target)⟩，Δ = 键两端格点的自旋单线态配对湮灭。
  SU(2) 对称下 a↔d、b↔c 等价（源码注释 `<B>=<C>`、`<A>=<D>`），
  项目合成公式 ⟨Δ†Δ⟩ = 0.5(a − b − c + d) 与之一致 **[源码+数据]**。
- 弦因子：`inst_op`（f = (−1)^N）仅插 bond 内部中间点；最近邻 bond
  无内部点，ref→target 之间的长距离连接用**恒等算符**（
  `MeasureFourSiteOpGroup` 的 `MoveTo` 用 id_op）**[源码]**。相位约定
  由数据的 SU(2) 关系自洽性支撑（ad/bc 误差实测 <1e-6）**[数据]**。

### 1.2 三个键方向 **[源码]**

- XC 圆柱：格点编号 i = x·Ly + y（Ly=4），x 方向周期性（周期 2·Lx=50 列）。
- `HoneycombXCCylinder::ClassifyNearestNeighbor`：同列竖直键按
  (y_min+x)%2 分 **A/B**，同行水平键为 **C**。
- 坐标几何（SiteCoordinate）：C 键沿 x 轴（圆柱轴向，θ=0°），
  A/B 键与 x 轴夹角 ±120°（横向短键）；三键等长。项目侧
  `_refbond_direction` 与该分类逐位一致（49_50→A、50_51→B、50_54→C）**[源码]**。
- **物理含义**：C 键沿圆柱长度方向（长方向），A/B 键横跨圆柱宽度
  （窄方向，Ly=4 仅 2 胞宽）。

### 1.3 数据文件与可用关联量 **[数据]**

- 12 文件/refbond：`scs{X}{a|b|c|d}_fix_refbond_{i}_{j}.json`，
  X∈{A,B,C} 为目标键方向，格式 `[[i,j,k,l], [re, im]]`（复数保留）。
- refbond 三个：49_50（A 键）、50_51（B 键）、50_54（C 键）；
  每 refbond 的 target 键 72-74 条（全量），三 refbond 距离范围
  [1.5, 55.5]，公共距离（逐键）90 个。
- 每文件提供 ⟨Δ_X†(r) Δ_ref(0)⟩（ref 固定为具体键）。四通道合成后，
  三个 refbond 数据联合可构造 **3×3 键方向矩阵**：
  M_αβ(r) = ⟨Δ_α†(r) Δ_β(0)⟩，α,β ∈ {A,B,C}。
- 复值数据的虚部全库实测：4 doping × 36 文件 max|Im|/max|Re|
  = 4e-12 ~ 5e-8（**机器零**）**[数据]**。

## 2. d+id 物理判据复核

### 2.1 两个 d-wave 基函数 **[源码+原理+数据]**

坐标系（C 键沿 x 轴，A/B 键与 x 轴夹角 ±120°）下的 d-wave 投影：

- d_{x²−y²}：投影 ∝ (2cos0°, 2cos120°, 2cos240°) = (2, −1, −1)，
  键序 (C, A, B) → **d₁ = (2Δ_C − Δ_A − Δ_B)/√6**
- d_{xy}：投影 ∝ (0, 2sin120°, 2sin240°) = (0, √3, −√3)，
  键序 (C, A, B) → **d₂ = (Δ_A − Δ_B)/√2**

与您给出的候选系数一致，但**键对应顺序必须为 (C, A, B)——"2" 在 C 键**
（不是按文件名 A/B/C 的任意排列）。数据佐证：对角关联
|C_CC|/|C_AA| ≈ 1.8~10.6（C 键主导）且 |C_AA|/|C_BB| = 1.00
（A/B 严格简并）——与 d₁=(2,−1,−1) 的幅值结构一致 **[数据]**。

整体符号（d₁ 的正负）无法从现有数据确定（见 2.3 边界），但
**相位分析只关心两个通道的相对相位**，整体符号不影响 arg C_12 判据。

### 2.2 配对关联矩阵与手性指标 **[原理+数据]**

- C_mn(r) = Σ_αβ v_mα v_nβ ⟨Δ_α†(r) Δ_β(0)⟩，m,n∈{1,2}。
- 判据：理想 d+id 下 Δ_d2/Δ_d1 = ±i → **arg C_12(r) ≈ ±90°** 且
  C_11 ≈ C_22；实值态下 arg C_12 ∈ {0°, 180°}。
- 手性指标 χ_d(r) = 2Im C_12/(C_11+C_22)：定义成立（分母实测为正，
  C_11 主导且正）**[数据]**。实测 χ_d ≈ 0（虚部机器零）。
- 归一化交叉关联 R_12 = C_12/√(C_11·C_22)：**当前数据上不适用**——
  实测 |C_22|/|C_11| ~ 1e-10（d_xy 通道近零），R_12 分母趋零、
  数值剧烈发散（实测 0.006~9475 波动）**[数据]**。建议不采用 R_12
  作为主指标；用 arg C_12 + 幅值门控 + χ_d 汇总。

### 2.3 关键数据事实（判据适用条件）**[数据]**

1. **虚部全库机器零**（max|Im|/|Re| < 5e-8，4 doping 全部）：复值
   种子方案收敛的基态 SC 关联是实值（机器精度）→ 无 TRSB 信号。
2. **d_xy 通道 ≈ 0**：|C_22|/|C_11| ~ 1e-10 ~ 1e-12（全 doping）——
   A/B 键配对严格同号简并。即使有复相位，d+id 的两个分量之一缺失。
3. **C 键符号不可得**：非对角 ⟨Δ_C† Δ_A⟩ 幅度远小于对角（噪声下），
   无法区分 d_{x²−y²}（C 与 A/B 反号）与各向异性 s 波（同号）——
   这是当前数据的**能力边界**，报告须如实标注。
4. 判据适用性结论：**arg C_12 ±90° 平台判据成立且可计算**，但在
   当前数据上的预期结果是否定的（arg ∈ {0°,180°}）；C_11≈C_22 的
   理想 d+id 条件也远不满足（C_22 ≈ 0）。d+id 的判定是"未发现
   手性证据"的否定性结论，不是"判据失效"。

### 3.1 距离对齐的关键技术事实 **[数据]**

- 逐键对齐失败：9 个 (α,β) 组合的键中点距离集合两两错位，
  **逐键/细 bin（容差 ≤0.5）公共距离 = 0**。
- **粗 bin（容差 ~2.0）下公共 bin = 27 个**（覆盖 r≈1.5~55）——
  相位平台分析可行但距离分辨率受限（27 点）。
- 原因：不同 refbond/键方向的 target 键中点几何错位（A/B 键中点
  横向偏移 √3/4 等）。分析器必须采用**距离容差分组**（或最近 bin
  匹配），不能逐键对齐。

## 4. 相位分析器设计

### 4.1 输入

- 三个 refbond × 12 文件的全量解析（不过滤 allowed_cond——衰减分析
  的纵向通道过滤口径不适用于相位矩阵；需全量 target 键）。
- 输入参数：N、t/J、doping、bond_dim、refbond 列表（或自动发现）、
  距离 bin 容差（建议默认 2.0，可配置）、幅值/相位阈值（可配置，
  默认值需授权）。

### 4.2 核心计算流程

1. 12 文件 × 3 refbond 解析为复数 ⟨Δ_X† Δ_ref⟩（0.5(a−b−c+d) 复组合）
2. 逐 (α,β) 按键中点距离容差分 bin，bin 内取复均值 → M_αβ(r)
3. 公共 bin 集合（9 组合全有值）→ 逐 bin 3×3 矩阵
4. d-wave 旋转：C_11、C_22、C_12、C_21（d₁=(2C−A−B)/√6，
   d₂=(A−B)/√2，键序 (C,A,B)）
5. 相位通道：φ_12(r) = arg C_12(r)（圆周统计）、χ_d(r)
6. 幅值门控 → 平台识别 → 汇总报告

### 4.3 幅值过滤（多判据，不设单一绝对阈值）**[原理]**

1. **噪声底标尺**：|C_12(r)| 与衰减分析同款 effective noise floor
   （远距尾部中位数/组内离散度/绝对下限取最大）比较；低于
   noise_floor × prom_factor（默认 3.0，需授权）的点标记无效
2. **D 档一致性**：两档（或多档）D 之间 |C_12(r)| 的相对变化；
   超阈值的点标记不收敛
3. **尾部噪声区间**：复用衰减分析的 r_max 噪声截断口径
4. 无有效点时不输出相位结论（insufficient，不伪造）

### 4.4 圆周统计与平台识别 **[原理，阈值待授权]**

- 圆周均值/圆周标准差（179° 与 −179° 视为接近，勿算术平均）
- 平台候选条件（建议值，**待物理授权**）：
  1. 连续有效距离点 ≥ 3
  2. 各点相位与目标（+90° 或 −90°）偏差 ≤ 15°（圆周距离）
  3. 平台窗口内圆周标准差 ≤ 15°
  4. 各点通过幅值门控（§4.3）
  5. 若多档 D：各档平台符号一致
- 分别识别 +90° 与 −90° 两个方向；同时输出 0°/180° 分类
  （实值退化情形）

### 4.5 实值极限与退化处理 **[数据]**

- 实值数据（或虚部机器零的复值数据）：Im C_12 ≈ 0 → arg ∈ {0°,180°}。
  分析器输出"无手性相位（实值基态/虚部机器零）"——**不得**因相位
  接近 90° 的单个噪声点判 d+id（±90° 平台的判据本身排除了这一点）。
- 实部正 → 0°、实部负 → 180°；实部虚部同近噪声 → 相位标记无效。

### 4.6 输出与统一入口接口

- 输出 AnalysisReport（复用现有契约）：classification = 
  `chiral_phase_candidate`（±90° 平台）/ `no_chiral_phase`（实值退化
  或无平台）/ `insufficient`（幅值门控后无有效点）/ `inconclusive`
  （结果矛盾）；payload 含逐距离 φ_12、χ_d、幅值门控标记、平台报告、
  各档 D 一致性检查。
- 经统一入口 `run_analysis(observable, operation)` 新增路由
  （observable = `sc_pairing_phase`，operation = `analyze`）；
  不修改现有路由与输出格式。

| 截断误差 | 同量级（~1e-14，d3_25 对比报告；d2_25 待正式提取 [待验证]） | **[数据，部分]** |

**亚稳态判断评估**：ΔE = 0.78（2.9%），跨 real 两档与 complex 三档 D
稳定不消失，粒子数/尺寸/参数一致 → **实值亚稳态判断充分成立**。
三者区分明确：
1. 复值计算找到更低变分解 ✓（变分空间包含性保证 E0_c ≤ E0_r）
2. 实值停留在较高能量局部极小（Néel 序陷阱）✓（D 收敛但能量高）
3. 复值低能态具有手性配对特征 ✗（虚部机器零，无 TRSB）

正负手性初态交叉验证：当前无 ±i 种子独立计算。**当前不需要**
（无手性信号时交叉验证无对象）；若未来某 doping 出现 ±90° 候选，
最小验证方案 = 种子 |a⟩−iε_c|b⟩ 重算并检验 χ_d 反号。

## 7. N200/N400 计算策略复核

- 情况判定：**情况 C**——N200 复值无可靠超导手性信号（虚部机器零
  + d_xy 通道 ≈ 0，全 4 doping）→ **复值 N400 无需优先计算**，
  维持"暂缓"决策 **[数据]**。
- 复值 d1_100 不计算的依据修正为：**缺乏可靠超导候选证据**（实值
  d1_100 的 SC 关联无幂律形态；指数衰减本身并不禁止相位关系，但
  关联幅值进入噪声区间后相位失去物理意义——不以其"数学上不可能
  出现相位"为由）**[原理]**。
- 复值多 N 能量：继续（E∞(δ) 复值口径 + 亚稳态复核用途成立）。
- 结论语言边界：**不得**将"当前参数无手性信号"表述为"二维
  热力学极限下不存在 d+id"；限定为"Ly=4 窄圆柱、N=200、
  t/J=3、4 个 doping 下未发现 TRSB/d+id 证据"。配对各向异性
  （C 键轴向主导、A/B 横向简并、d_xy 分量≈0）是独立的可发表观测。

## 8. 论文证据分级（结论语言框架）

1. **第一层（超导关联倾向）**：SC 衰减分类/指数、配对 SF、doping
   演化、D 收敛——软件已齐备，直接生成。
2. **第二层（d-wave 配对特征）**：键方向幅值结构（C 主导、A/B 简并）、
   d₁/d₂ 通道分解——本审计已产出初版观测（§2.3），分析器落地后
   形式化。
3. **第三层（d+id 手性候选证据）**：arg C_12 平台、交叉关联幅值、
   距离稳定性、D 一致性、正负手性互验——分析器输出；当前数据预期
   结论"无手性证据"。
4. **第四层（结论边界）**：Ly=4 有限宽度、N=200 单尺寸、准一维特征、
   二维极限未建立——论文必写段落。

## 9. 最终结论（对应您的问题）

1. **现有数据是否足以构造可靠的 d+id 分析器？**
   **足以**（[数据]）：3×3 键方向矩阵可由三个 refbond 数据联合构造，
   但必须在粗距离 bin（容差 ~2.0，公共 27 点）下进行；逐键/细 bin
   对齐不可行（公共点 0）。
2. **如果不足，缺少哪些数据？**
   对"判定 d+id"不缺。两项可选补充（低优先）：±i 双种子计算
   （正负手性互验，仅当出现 ±90° 候选时必要）；跨键符号测量
   （区分 d_{x²−y²} 与各向异性 s 波——当前 C 键相对符号在噪声下
   不可得，[数据] 能力边界）。
3. **推荐采用什么物理判据？**
   arg C_12(r) 的 ±90° 平台（圆周统计 + 连续 ≥3 有效点 + 幅值门控
   + D 档一致性）+ χ_d 汇总；C_11≈C_22 作为理想 d+id 的一致性检查；
   **弃用 R_12**（C_22≈0 数值发散，[数据]）。
4. **是否应该先补充测量再开发分析器？**
   **先开发分析器**（[原理]）：数据已足以给出结论（预期"无手性
   证据"），分析器落地后其输出同时就是论文第三层证据的正式呈现；
   补充测量等分析器验证后按需启动。
