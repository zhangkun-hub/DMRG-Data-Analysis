## 一、课题要回答什么（通俗版）

你的课题：在 honeycomb 晶格 t-J 模型上，用 DMRG 研究**掺杂下的
超导倾向**，重点考察是否有 **d+id 手性超导**（d_{x²−y²} 与 d_{xy}
两个分量以 ±90° 相位差叠加、破坏时间反演对称的超导态）的迹象。

论文要回答的问题可以分解为两层：

1. **有没有超导倾向？** 核心看四点配对关联 ⟨Δ†Δ⟩ 随距离怎么衰减：
   - 像**幂函数**一样缓慢下降（幂律衰减）→ 配对有准长程特征，超导候选
   - 像**指数**一样快速消失 → 配对有能隙，没有超导序
   再配合配对结构因子在 q=0 处是否增强、自旋/电荷/单粒子关联的
   交叉验证，形成证据链。
2. **如果是 d 波，是不是手性的 d+id？** 实值计算**永远无法区分**
   普通 d 波和 d+id（d+id 的实部投影就是一个普通 d 波分量）。唯一
   直接信号：**复值基态计算**下配对关联的**相对相位 φ(r) 是否出现
   ±90° 平台**（普通组合只能是 0° 或 180°）。这就是为什么复值计算
   是论文的关键一步。

注意一个已知事实：窄圆柱（Ly=4）下 Mermin-Wagner 定理禁止真长程序，
所以我们的结论语言是"准长程配对倾向/候选证据"，不是"证明是超导相"。
硕士论文这样写完全成立，且更诚实。

   单粒子 + 能量日志）——注意**全部物理量都要重测**，不是只测一个

### 3.2 ~~软件侧复值数据解析适配~~【已完成，2026-11-05，commit 83af0ad】

原问题：超导/自旋/密度记录类的 `extract_data` 只取实部、丢弃虚部，

已完成方案：`DensityRecord` / `CorrelationRecord` / `SuperCorrRecord`

`.sup_corr`）返回实部 float，**下游分析代码零修改**；新增
`*_complex` 属性访问完整复数。实值数据下数值完全不变（42 套测试 +
3 条回归基线全过）。复值数据落地后可直接解析；配对对称 phase 通道
