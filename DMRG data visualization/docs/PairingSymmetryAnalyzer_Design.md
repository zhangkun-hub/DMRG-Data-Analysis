## 1. 设计目标与职责边界

### 1.1 要解决的物理问题

在 honeycomb 晶格 t-J 模型 XC 圆柱的 DMRG 数据上，检验超导配对关联的
**键方向对称性**：三键方向关联幅度指标（见 §4.2 的操作性定义）的相对
大小模式与 s 波、实 d 波等候选对称性的相容性；为未来 d+id 检验明确
数据前提。

**本分析器判定的是"关联幅度指标的对称性模式"，不是配对序参量本身**
（两者关系是待验证物理假设，见 §4.1 三层次区分）。

### 1.2 职责边界（与其他模块的关系）

| 模块 | 职责 | 与 PairingSymmetryAnalyzer 的边界 |
|---|---|---|
| `SuperCorrDecayAnalyzer` / 通用衰减核心 | 单方向 <Δ†Δ> 的衰减分类与包络拟合（K/ξ、窗口、稳定性） | 输入之一：其输出只作证据与质量门，**不重复拟合** |
| `SCPairStructureFactorEstimator` | 固定参考键 × 单方向的受限结构因子（含通道分解） | 输入之一：q 空间辅助证据；其受限语义原样引用 |
| `SC_Exponent_Summary`（D1） | K/xi 跨数据汇总与四态分类 | 输入之一：只用于稳定性评级与条件筛选；注意 D1 行**不含包络振幅 A 字段**（见 §5.4） |
| `Cross_Doping_Summary`（P4.3） | 跨 doping 受控汇总与机械可比性 | 复用其 refbond 发现/失败机制与可比性规则；本分析器不产生新的跨 doping 趋势结论 |
| `Phase_Diagnosis`（P1/P2/P3） | 证据汇总、可比性审计、充分性检查 | 输出经 `AnalysisReport` 进入 P1 汇总；P2 对本分析器的处理见 §7.2 |

**不做**：不判定超导相是否存在；不判定 d+id/TRSB；不判定任何相态；
不计算新的跨组平均统计量；不修改任何测量程序。

## 2. 物理定义与数据约定

### 2.1 四通道算符与合成公式（已核实）

依据 `DMRGtJModel/src/measureSC.cpp`（算子序列 `sc_phys_ops_a/b/c/d`）与
`Physical_Quantity/SC_Pair_Structure_Factor.py` 的 `DEF_SC_PAIR_CHANNELS`
常量，两处一致：

```
a = <c†_i↑ c†_j↓ c_k↑ c_l↓>
b = <c†_i↓ c†_j↑ c_k↑ c_l↓>
c = <c†_i↑ c†_j↓ c_k↓ c_l↑>
d = <c†_i↓ c†_j↑ c_k↓ c_l↑>
```

- **单重态**：`<Δ†_s Δ_s> = 0.5(a − b − c + d)`（Python 侧已实现：
  `SuperCorrProcessor.Combined_super_correlation`，Δ† 定义
  (c†_i↑c†_j↓ − c†_i↓c†_j↑)/√2 已逐项核对）
- **三重态**：`0.5(a + b + c + d)`——同文件可导出，**当前 Python 分析器
  未实现**，仅作未来扩展记录

### 2.2 A/B/C 键方向与定向约定（已核实）

依据 `DMRGtJModel/src/honeycomb_lattice.h` 的
`HoneycombXCCylinder::ClassifyNearestNeighbor`（C = x 相邻且 y 相同的
水平键；A/B = 锯齿键按子格 parity 二分），并经实测键向量交叉验证：

- **A = 60° 线**（锯齿键，parity 偶类）
- **B = 120° 线**（锯齿键，parity 奇类）
- **C = 0° 线**（水平键，不跨 y 边界）

**定向约定**：后续任何模式向量（如 (1, e^{±2πi/3}, e^{∓4πi/3})）一律按
**分量顺序 (A, B, C) = (60°, 120°, 0°)** 解释；循环置换标签或取复共轭
会交换 ± 相位标签。该约定只影响模式书写，不改变"相位不可测"的限制
（§4.6）。

### 2.3 参考键类别

- N200：`49_50`（A 类）、`50_51`（B 类）、`50_54`（C 类）
- N400：`97_98`（A 类）、`98_99`（B 类）、`98_102`（C 类）

两尺寸均恰好覆盖三个类别（每类一个参考键）。参考键类别是本分析器
分组比较的基本身份之一。

### 2.4 坐标系与归一化

- 坐标为 `HoneycombXCGeometry` 的笛卡尔坐标（基元 8 格点、4 行、胞距
  3a；y 为周期方向，周长 Ly = 2√3a；x 为开放方向）
- 结构因子归一化 1/N（公共核 `compute_structure_factor`）；衰减分析直接
  拟合关联值（无额外归一化）
- 动量网格 `xc_momentum_grid`：qy = 2πm/Ly（m=0..3 默认采样），qx 为
  开放方向连续扫描；C1 审查结论：**Γ 在网格上（n_qx 为奇数时），
  K/K′=(0, ±4π/(3√3a)) 不在 Ly=4 网格上（对应 m = 4/3 非整数）**

## 3. 现有数据与接口约束

### 3.1 两条解析路径（必须区分）

| | 衰减路径 `SuperCorrRecord.extract_data` | 结构因子路径 `parse_direction_file` |
|---|---|---|
| 解析范围 | 参考键须在左 1/4 边界 + `allowed_cond` 过滤（只保留与参考键平行且近水平的目标键；实测每方向 18~19 条） | 全量解析方向文件（实测 A/B 74 条、C 72 条） |
| wrap 键 | 被 `allowed_cond` 滤除，无 wrap 键 | **包含 wrap 键**（A 18 条、B 19 条） |
| 用途 | SC 衰减分析（D1 指数汇总与本分析器的数据源） | SC 配对结构因子（A1+A2 集成后的数据源） |

本分析器的幅度/符号证据以**衰减路径**为主（它产出拟合振幅）；结构
因子路径只作 q 空间辅助证据，且受 §3.3 限制。两种口径不得混用。

### 3.2 数据完整性事实

- 每参考键目录有 3 方向 × 4 通道 = 12 个文件，当前数据齐全
- **不存在完整配对关联矩阵**：每个尺寸只有 3 个固定参考键 × 单方向
  目标键集合的受限数据，不得描述为"参考键 × 目标键全矩阵"
- 全部实测关联值为实数（Python 模块显式拒绝复数输入）
- **当前数据无长距离平台**：D1 实测 36 行分类为 power_law /
  oscillatory_power_law / non_monotonic / complex_decay，**无 constant
  类**；r_max ≈ 36 处已接近噪声底。这一事实是 §4 方法设计的出发点，
  任何方案不得假设或暗示平台存在

### 3.3 已知几何问题（已实证，未修复）

A/B 方向文件中 18~19 条目标键是跨 y 周期边界的 wrap 键。结构因子路径
用**未折叠中点坐标**计算相位：wrap 键中点 y 误差恰为 −√3a，相位误差
exp(−i·qy·√3a) = (−1)^m。影响范围：**仅奇 qy 扇区（m=1,3）**；
Γ 与偶 qy 扇区完全不受影响。衰减路径不受影响（wrap 键被滤除）。

未来修复建议（不在本文档任务范围）：在结构因子路径将 bond 中点 y
折叠回 [0, Ly) 后再计算相位；修复前，奇 qy 扇区的 S(q) 不得用于
对称性判定。

### 3.4 契约与数据结构事实（为 §5/§7 设计所依赖）

- `FitResult`（`Correlation_Decay_Analyzer.py`）暴露：`params`（含
  envelope 振幅 A 与 K/ξ）、`param_errors`（对角线误差）、`aicc/bic`、
  `fit_space`、`window`、`error_source`。**不暴露参数协方差矩阵**
  （A 与 K 的拟合相关无法从现有字段直接获得）
- `DecayAnalysisResult.payload` **不包含 `group_raw`**：原始 bond 级
  数据只存在于中间对象 `PreparedData.group_raw`（分组后的原始点），
  结果对象只保留 `n_raw_points` 等计数。**bootstrap 需要从调用方持有
  的原始记录列表（record_list）重采样，或扩展结果对象**——按现状
  设计为"待扩展"，不写成已支持（§4.7）
- D1 行（`SC_Exponent_Summary`）包含 `exponent_type/exponent_value/
  exponent_error/verdict/rel_mad_K/model_consistency/spearman_rho` 等，
  **不含包络振幅 A**；振幅须取自 `payload.envelope_fit.params['A']`
  或跨 doping 汇总行的 `params_json`（两者同源，逐位一致已实测验证）
- `STATUS_OK` = 计算正常完成；`STATUS_INCONCLUSIVE` = 计算完成但无
  可用的有意义结果（如信号全无效）；`STATUS_FAILED` = 输入为空/结构
  损坏。三者是**运行状态**，不承载候选判定（§6.3 映射表）

## 4. 核心分析方法（设计）

### 4.1 三个证据层次（必须逐层区分，不得跨层断言）

1. **层次 1（直接可估）**：各 (参考键类, 目标键类) 组合的关联函数
   C_{αβ}(r) 及其包络拟合振幅 Â_{αβ}（§4.2 操作性定义）。这是数据的
   直接函数，不依赖任何物理假设（只依赖拟合模型选择）。
2. **层次 2（条件可比）**：在共同衰减形式、公共有效窗口、模型适配性
   通过验证后（§5.2 质量门），不同组合的 Â_{αβ} 可作相对比较（比值、
   秩结构）。此时 Â 仍只是**关联幅度指标**。
3. **层次 3（需物理假设）**：把 Â_{αβ} 解释为 |Δ_α||Δ_β|（配对序参量
   幅度乘积）需要代数 ODLRO 因子化假设——**当前数据无平台、该假设
   未验证**，任何结果都不得写成层次 3 结论。

### 4.2 操作性包络振幅 Â_{αβ}

- 定义：在**固定公共拟合窗口** [r_min, r_max] 内，对组合 (α,β) 的
  <Δ†_α Δ_β>(r) 作包络拟合（power：A·r^(−K) 或 exp：A·e^(−r/ξ)，
  |C| 空间），取拟合参数 A 作为 Â_{αβ}
- **依赖声明（必须随结果输出）**：Â 依赖 (i) 拟合模型形式（K/xi）；
  (ii) 窗口；(iii) |C| 与 signed 的拟合空间选择；(iv) 噪声水平；
  (v) 与指数 K/ξ 的拟合相关（协方差当前不可得，见 §4.7）
- **Â_{αβ} 不是序参量幅度**：它是关联的包络振幅指标。仅当层次 3
  假设被独立验证（未来完整配对矩阵、更大尺寸平台等）后才能作序参量
  解读；本版本输出一律标注"关联幅度指标"
- **硬规则**：不同组合的 Â 只在共同窗口 + 相同包络形式下可比。
  K 与 xi 是不同物理量（幂指数 vs 关联长度），**其拟合振幅不得混入
  同一比值或同一矩阵**

### 4.3 两级可辨识性框架（矩阵拟合）

把可比组合的 Â 组织成 3×3 矩阵（行 = 参考键类 α，列 = 目标键类 β）。
**矩阵只有在其元素满足 §4.2 的共同窗口与形式条件时才有意义**；
不满足的组合视为矩阵缺失项（部分矩阵）。

**第一级：一般秩一模型 A ≈ σ·u·v^T**
- 参数化：σ > 0，‖u‖ = ‖v‖ = 1（整体尺度规范消除冗余）；连续参数
  3 + 3 − 1 = 5 个，完整矩阵 9 个观测 → 4 个残差自由度
- 用途：检验"参考键依赖与目标键依赖可分离"（秩一近似成立）；u 与 v
  的差异是参考键依赖的直接诊断
- **秩一拟合成功 ≠ 物理对称性成立**：它只说明数据矩阵近似可分；
  必须报告拟合残差、条件数与逐项不确定度
- 部分矩阵：缺失项按缺失处理（不加 0、不插值）；连续参数可辨识性由
  Jacobian 秩判断；有效组合数不足时降级（§6.2）

**第二级：对称约束模型 A ≈ m·m^T**
- 物理前提：层次 2 的幅度指标可解释为"同一向量 m 的外积"（比一般
  秩一更强：行依赖与列依赖同源）。对称模型连续参数 3 个（对称 6 个
  独立项 → 3 个残差自由度）
- **u ≈ v 检验**：仅在统一参数化（σ、单位范数）后比较 angle(u, v)
  与拟合残差差；比较须带误差（bootstrap），不得裸比较点估计
- **PSD 诊断**：m·m^T 对任意实向量 m 恒为半正定（线性代数事实）。
  若加权拟合的 Â 的最小特征值显著为负（显著性经 bootstrap 分布
  判断），则对称模型被拒绝——这是有效的模型违反诊断，但噪声下
  不得凭单次点估计判断
- 对称模型成立 + 残差通过，**仍不等于证明存在配对凝聚或确定了
  超导对称性**（层次 3 假设未验证）

**可辨识性诊断清单（设计，阈值待校准）**：矩阵条件数；有效观测数；
秩亏（部分矩阵）；接近零的 m 分量（对应幅度接近零的类别，其相对
误差发散——(0,1,−1) 型模式的固有难点）；bootstrap 失败。阈值一律
列为设计参数（命名如 `cond_max`、`min_effective_entries`），通过合成
数据 + 真实数据校准，不得在文档中指定未经验证的数值。

### 4.4 候选对称性匹配（magnitude 通道）

将对称模型估计出的幅度比 (|m_A|, |m_B|, |m_C|)（归一化后，带不确定度
区间）与候选模式比较：

- `s`：(1, 1, 1)
- `d_real`：E2 二重态的实伙伴 (2, −1, −1) 与 (0, 1, −1)（分量为
  (A,B,C) 顺序；两者幅度 anisotropy 分别为 2:1:1 与 0:1:1）
- `magnitude_degenerate`：|m_A| ≈ |m_B| ≈ |m_C|（与 s 和 d±id 均相容）

**幅度与符号的作用（严格区分）**：
- 幅度 anisotropy 可以区分 s 与 d_real（1:1:1 vs 2:1:1/0:1:1）；
- (2,−1,−1) 与 (0,1,−1) 的**定向区分需要符号信息**（§4.5），仅凭
  幅度只能把 d_real 定到"二重态伙伴之一"；
- **不得仅凭幅度模式匹配确证实 d 波**：还须通过符号证据（若可用）、
  跨参考键一致性、质量门与不确定度区间检验。

### 4.5 符号证据通道（sign，独立于 magnitude）

- 原理：实值态的相对符号是 0/π 型；对称模型下 Â 的符号结构为
  s_α·s_β（整体符号不可定）。**这是原则上的信息存在，不代表所有
  实值数据都足以可靠提取**
- 提取条件（全部满足才输出符号证据）：(i) 该组合的有符号关联在拟合
  窗口内无过零/无振荡主导；(ii) signed 空间拟合（`fit_space='linear_C'`
  路径）质量可接受（r2 等，阈值待校准）；(iii) 窗口内符号稳定
  （跨子窗口符号翻转 → 不可用）
- 不可用时的处理：符号状态标记 `unavailable` 或 `evidence_insufficient`
  （§6.2），**不得从 |C| 包络振幅推断符号**；幅度分析结果保留
- 现有包络路径拟合 |C| 已丢失符号；D1 实测 36 行中 14 行
  oscillatory_power_law、19 行 non_monotonic → 多数组合可能不可用，
  符号通道的可行性是 UNVERIFIED（需真实数据试跑后确认）
- **严格区分**：符号结构（0/π）≠ 配对表示归属（还需幅度模式与基底
  约定）≠ 相对复相位（任意相位，不可测）。不得把实数符号模式写成
  完整复相位证据

### 4.6 相位证据通道（phase）

- 完整相对复相位（任意角度）在实值关联数据中原则上不可恢复；
  `imaginary_residual` 是受限数据共轭对缺失的产物，不是物理信号
- d+id / TRSB 类判定 → **`blocked_by_data`**（通道级，见 §6.2）；
  K/K′ 不可达（C1）进一步限制动量空间相位探针
- 未来解锁路径：复值 MPS 或 TRSB 敏感测量（§8.2 P1），不属于本分析器
  当前范围

### 4.7 不确定性处理（设计）

- 首选方案：**group_raw bootstrap**——对调用方持有的原始记录列表按
  bond 记录重采样、重跑包络拟合，得 Â 与比值分布。当前约束：
  `DecayAnalysisResult.payload` 不含 group_raw（见 §3.4），需扩展结果
  对象或由调用方传入记录列表——**设计标注为"待扩展"**
- **不得假定 9 组统计独立**：所有组合共享同一 MPS 基态，组间相关
  存在；若组间协方差不可估计（当前数据结构不支持），如实输出
  "协方差不可估计"，误差条只覆盖单组合采样变异性，不得虚构独立性
- bootstrap 的统计解释：反映记录集内部的采样变异性；**不包含 DMRG
  截断误差与系统误差**，报告须注明
- 降级规则（设计）：bootstrap 失败、有效组合数低于下限、条件数超标、
  置信区间覆盖多个候选模式 → 状态降级（§6.2），不输出点估计结论

### 4.8 可提取 / 不可提取量的严格边界（汇总）

**可提取（受质量门约束）**：
- 共同窗口/共同形式下的包络振幅指标 Â_{αβ} 及其相对比值
- 矩阵秩一结构诊断（一般/对称两级）
- 幅度 anisotropy 的候选匹配（s / d_real 伙伴 / 幅度简并）
- 符号结构（仅满足 §4.5 条件的组合；整体符号除外）

**不可提取（现有数据）**：
- 相对复相位、d+id 确证、TRSB 证据（`blocked_by_data`）
- 序参量幅度本身（层次 3 未验证）
- K/K′ 处的动量空间配对检验（网格不含 K/K′）
- 超导相存在性的证明

## 5. 输入数据、质量门与完整性校验（设计）

### 5.1 每条件必需输入

对每个 (doping, N, bond_dim)：
1. 3 个参考键目录 × 3 方向 × 4 通道 = **36 个 SC 数据文件**
2. SU(2) 对称性检查结果（`SuperCorrProcessor.symmetry_check`：a↔d、
   b↔c 两个相对误差）
3. 调用方持有的 SC 衰减记录列表（衰减路径合成结果，用于 §4.7
   bootstrap；当前 payload 不含 group_raw）
4. D1 指数汇总行（同一条件的 SC 衰减行，作质量证据）

### 5.2 质量门顺序（设计；顺序即执行顺序）

1. **文件与数据完整性**（§5.3）：36 文件、逐文件 NaN/Inf 检查、
   通道间参考键一致、目标键集合一致、重复条目检查
2. **衰减模型可比性**：包络形式一致（K/K 或 xi/xi，**K 与 xi 不得
   混合比较**）；振荡特征可比（过零组合与无过零组合**分别处理**——
   即振荡证据分层，见下）
3. **振荡证据分层**（5B-1 实现，"分别处理"的具体语义）：
   - 按**公共比较窗口内**的振荡证据分层（`osc` / `non_osc` /
     `unknown`；公共窗口内的带符号原始记录过零证据为准，不用元素
     私有窗口的过零计数，绝不由 |C|、振幅 A 或非负向量 m 推断符号）
   - 层判据：strong/moderate 证据 → `osc`（保留证据等级）；公共窗口
     内存在**可靠过零**（翻转点对两侧 |C| 均高于该元素的
     final_noise_floor）→ `osc`（即使证据级别为 weak/possible/none）；
     无过零且证据可用 → `non_osc`（按非振荡处理，不表示已证明不存在
     振荡）；证据缺失、过零全部发生在噪声底附近、或可靠性不可判定
     → `unknown`（不强行归类）
   - 各层**独立构建公共窗口与矩阵**（层内窗口由层成员私有窗口交重算，
     不复用分层前的组窗口或元素旧拟合）；层内仍执行全部既有质量门
   - **禁止默认跨层比较**（5B-0 合成实验：|C| 包络振幅偏差元素相关，
     跨层混排污染矩阵结构；跨层比较一律拒绝并在报告中记录原因）
   - `osc` 层必须附带**振幅偏差警告**：|C| 包络拟合振幅存在与节点
     位置、q/phi、窗口及噪声底相关的系统偏差（5B-0 合成实验观察
     振幅偏差约 −13%~−69%、跨元素相对极差可达 ~114%——为特定实验
     条件下的结果，不是普适误差界，不得作为校正系数或置信区间）；
     层内拟合成功不等于振幅可直接用于可靠候选匹配；未完成 q/phi
     逐元素校正，振荡偏差未被消除
   - **过零可靠性阈值未校准**：可靠过零以 final_noise_floor 本身为
     标尺（翻转点对两侧 |C| 均高于噪声底），任何倍率因子均未校准，
     不引入生产阈值
   - 分层不豁免任何既有质量门（形式一致性、有效点数、有限值、拟合
     成功、Jacobian 秩、条件数、SU(2) 等）
4. **公共窗口**：D2.1 实测 9 组合 r_min 漂移 1.5~19.5、且 9 组合
   全部存在 K/xi 漂移——**不得默认公共窗口存在**；公共窗口不存在或
   窗口内有效点数不足 → 该组合不入矩阵（部分矩阵）或整体
   `evidence_insufficient`，**不得强行缩短窗口或混用模型来凑全矩阵**
5. **SU(2) 质量门**：N200 实测 ~1e-4（通过，仍需记录）；**N400 实测
   0.008~0.144（超过阈值，不得用于对称性分类）**；该条件 → 幅度通道
   `evidence_insufficient`（原因入报告）
6. **矩阵拟合与候选判定**（§4.3/4.4）：仅对通过 1-5 的组合进行

### 5.3 完整性校验清单（设计）

| 检查项 | 失败处理 |
|---|---|
| 36 文件齐全（缺任一文件） | 沿用既有失败机制：数据级失败（FileNotFoundError）原样传播或记录失败行（Cross_Doping 模式）；不进入通道状态机 |
| 逐文件 NaN/Inf 值检查 | 非有限值计数入报告；全部非有限 → 该组合不可用；部分非有限 → 排除相应条目并记录 |
| 每方向四通道目标键集合一致（复用现有 frozenset 校验语义） | 该 (参考键, 方向) 组合不可用，列入 input_incomplete |
| 通道间参考键一致、同键重复条目 | 报告计数（复用 duplicate_pairs 语义）；不影响结构的不重复 |
| 参考键类别覆盖（三类 A/B/C 齐） | 缺失类别显式记录；幅度提取降级或按部分矩阵处理 |

### 5.4 D1 与稳定性指标的接入规则

- D1 行的 `exponent_type/exponent_value/verdict/rel_mad_K/

  - `rel_mad_K`/`model_consistency`/`spearman_rho` 只描述稳定性，

## 6. 分类状态与判定语义（设计）

### 6.1 三通道独立状态机

分析结果分三个**独立证据通道**，互不覆盖：

**幅度通道 `magnitude`**：
- `supported_candidate`：对称模型 + 质量门全部通过，幅度比（带不确定
  度区间）与候选 `s` / `d_real` / `magnitude_degenerate` 之一相容且
  跨参考键一致。**只表示关联幅度指标与候选相容，不表示物理确证**
- `inconclusive`：质量门通过但幅度比与多候选相容，或不确定度区间
  覆盖多个候选
- `evidence_insufficient`：质量门失败（SU(2) 超标、稳定性不足）、
  公共窗口不存在、有效组合数不足、bootstrap 失败等
- `input_incomplete`：文件齐全但通道级完整性失败（目标键集合不一致、
  参考键类别缺失、部分矩阵不满足可辨识性下限）
- 状态 = `blocked_by_data` 的情况：幅度提取所需假设本身不可验证时
  不适用（幅度是层次 1 量）；`blocked_by_data` 保留给相位通道

**符号通道 `sign`**：
- `extracted`：§4.5 全部条件满足，输出相对符号结构（整体符号规范外）
- `evidence_insufficient`：数据质量不足以稳定提取
- `unavailable`：组合存在过零/振荡/噪声主导，符号不可用
- 符号不可用时**幅度通道结果保留**，两通道独立报告

**相位通道 `phase`**：
- **恒为 `blocked_by_data`**（当前实值数据）：d+id/TRSB 类判定不可
  产生。这是**通道级状态**：幅度通道可同时给出 `supported_candidate`
  （或其它状态），互不覆盖；报告两者并存

### 6.2 状态互斥与降级

- 三通道状态彼此独立；单通道内状态互斥
- `magnitude_degenerate` 只是幅度通道的候选标签：**仅描述幅度简并**，
  与 s 波和 d±id 均相容，不是任何一方的确证，不是 TRSB 证据
- 降级方向固定：supported_candidate → inconclusive →
  evidence_insufficient（/ input_incomplete），不逆行

### 6.3 与 AnalysisReport 运行状态的映射（设计）

依据契约实际定义（§3.4）设计映射：

| 情形 | `AnalysisReport.status` | 依据 |
|---|---|---|
| 数据级异常（缺文件、解析失败）原样传播 | 不产生报告（异常传播）或失败行（Cross_Doping 模式 `_try` 捕获 FileNotFoundError/ValueError） | 既有机制，不改 |
| 分析运行完成，无论通道状态 | `STATUS_OK`（'ok'） | 契约：计算正常完成 |
| 全部组合信号全无效（如全 NaN） | `STATUS_INCONCLUSIVE`（'inconclusive'） | 契约："计算完成但无可用的有意义结果" |
| `STATUS_FAILED`（'failed'） | 不用于通道状态；仅由适配器的 None 输入映射 | 契约语义 |

**通道状态不写入 `status`**：写入结果结构的专用字段（如
`results.magnitude.state` 等，§7.3），避免与运行状态混淆。
`input_incomplete` 属于"分析可运行、输入不充分"的结果——运行状态仍为
ok，语义由通道字段表达；文件级缺失则走异常/失败行，两者不混。

## 8. 已知局限、风险与后续测量需求

### 8.1 已知局限（当前数据）

1. 受限单参考键数据，无完整配对矩阵
2. 实值关联，无相位信息；符号信息仅在部分组合可用（§4.5）
3. **无长距离平台**：层次 3 的序参量解释不可达（如实记录，不把包络
   振幅方案描述为已解决 ODLRO 不可观测的问题）
4. Ly=4：K/K′ 不可达（C1）
5. 每类参考键仅 1 个，统计稳健性有限；u≈v 对称性检验是主要诊断
6. wrap 键中点坐标问题（§3.3）影响奇 qy 扇区
7. D1 实测：9 组合全部存在 K/xi 形式漂移、r_min 窗口漂移 1.5~19.5
   → 全矩阵提取大概率不可行，部分矩阵是预期常态
8. N400 SU(2) 0.008~0.144 超标，不进入对称性分类
9. A↔K 拟合协方差与组间协方差当前不可估（§4.7）

### 8.2 测量需求（按优先级）

| 优先级 | 需求 | 用途 |
|---|---|---|
| P0 | **完整配对矩阵**（所有参考键 × 所有目标键；`measureSC_fix_ref` 已支持 `--refbond=i,j`，无需改 C++） | 解除受限语义、验证 u≈v 与跨参考键稳健性、层次 3 的前提检验 |
| P1 | **TRSB 敏感测量**（复值 MPS 或电流关联/纠缠谱等间接探针；需 DMRGtJModel 侧新能力） | d+id 相位检验的唯一路径 |
| P2 | 宽圆柱（Ly=6 或 9）数据 | K/K′ 可达（C1 结论 m=n/3） |
| P2 | N400 高 D / 多初态重算 | 解决 SU(2) 超标 |

### 8.3 主要风险与缓解

| 风险 | 缓解 |
|---|---|
| 把包络振幅比当序参量幅度比 | 三层次区分（§4.1）+ 输出标注"关联幅度指标" |
| 把幅度简并当 s 或 d+id 确证 | `magnitude_degenerate` 独立候选 + 语义声明 |
| 把 `imaginary_residual` 当 TRSB | 相位通道恒 blocked；定义与来源写入限制说明 |

| K/xi 混用 | §5.2 硬前置 + 测试保护（§9） |
| 全矩阵不可得时强行构造 | 部分矩阵规则 + 有效组合数下限 + 降级 |
| 窗口漂移被静默忽略 | 公共窗口为质量门；不满足即失败/降级 |

## 9. 验证计划与实施路线（计划，不新增测试文件）

### 9.1 测试计划（设计）

**单元测试**：
1. 两级矩阵模型的参数计数与拟合：一般秩一（u,v,σ）与对称模型（m）
   在合成矩阵上的恢复正确性
2. **秩亏与条件数**：接近秩一的带噪矩阵、接近零的 m 分量
   （(0,1,−1) 型）→ 可辨识性降级路径正确
3. **相同幅度、不同符号结构**的合成数据：幅度通道给出相同候选，
   符号通道（满足 §4.5 条件时）区分、不满足时正确标记 unavailable
4. 一般秩一与对称模型**差异**：行标度 ≠ 列标度的合成数据 → u≈v
   检验拒绝对称模型，报告参考键依赖
5. **不同衰减形式/窗口漂移/公共窗口不存在**：K 行与 xi 行混入被硬
   前置拦截；窗口不交 → 部分矩阵或 evidence_insufficient
6. **部分矩阵与有效组合数不足**：状态判定与缺失结构记录正确
7. K/xi 不得混用保护测试

**输入完整性测试**：缺文件、**重复文件/重复条目**、**非有限值**、
通道目标键集合不一致、参考键类别缺失 → 各自失败路径正确

**质量门测试**：SU(2) 超标、稳定性不足（verdict/rel_mad_K 等只进
评级字段）、bootstrap 失败 → 降级不降判定

**契约测试**：
8. `blocked_by_data` 与幅度 `supported_candidate` **并存**的 JSON 结构
   合法（三通道独立）
9. 严格 JSON 序列化（无 NaN/Infinity）、`AnalysisReport` status 映射
   （§6.3）、P1/P2 接入不报错

**真实数据验证**：N200（SU(2) ~1e-4）全 4 doping 运行，输出幅度
模式、部分矩阵结构、符号通道可用性统计与不确定性；N400 验证被
质量门正确排除。真实数据只覆盖其覆盖的路径，不推断 d+id

### 9.2 分阶段实施顺序（设计）

1. **阶段 1**：数据装配层——36 文件读取、逐文件 NaN/Inf 检查、
   通道一致性、参考键类别识别、record_list 传入（bootstrap 数据源）
2. **阶段 2**：可比性子集构造——K/xi 分列、共同窗口搜索、振荡特征
   分组（质量门 1-3）
3. **阶段 3**：矩阵拟合核心——两级模型、条件数/残差/PSD 诊断、
   部分矩阵处理、bootstrap 误差（含 group_raw 扩展）
4. **阶段 4**：三通道状态机与候选判定（§6）
5. **阶段 5**：契约集成（§7）与测试全量落地

每阶段验收：对应测试全过 + 真实数据输出与人工抽查一致；阶段 5 完成前
不宣称任何对称性结论。
